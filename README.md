# 🐔 Cock Clicker

**Cock Clicker** is a browser-based idle/clicker game built with **HTML, CSS and JavaScript**.

The goal is simple: click, earn cocks, buy upgrades, increase your production and evolve your rooster into stronger forms.

> 🚧 The game is currently under development.

## 🎮 Play the game

The game will be available through **GitHub Pages**.

## ✨ Current Features

* 🐔 Click to earn cocks
* 💰 Cocks per click system
* ⏱️ Passive cocks per second
* 👵 Grandma production upgrade
* 🏭 Factory production upgrade
* 🧪 Laboratory production upgrade
* 📈 Increasing upgrade prices
* 🧬 Evolution system
* ✨ Production multipliers
* 🎨 Custom game interface

## 🧬 Evolution

Cock Clicker uses an evolution system inspired by progression mechanics found in idle games.

As you progress, you can evolve your rooster into a stronger form.

When evolving:

* Your current cocks are reset
* Your buildings are reset
* Your upgrades are reset
* Your permanent production multiplier increases
* A new evolution stage is unlocked

The goal is to make every new run faster and more powerful than the previous one.
